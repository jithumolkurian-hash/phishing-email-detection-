# 📧 Phishing Email Detection using Machine Learning

## 📌 Overview
This project detects whether an email is **phishing or safe** using Machine Learning techniques. It analyzes email text and classifies it based on learned patterns.

---

## 🚀 How it works
- Text data is converted into numerical form using **TF-IDF Vectorization**
- A **Logistic Regression model** is trained on labeled email data
- The model predicts whether new emails are phishing or safe

---

## 🧠 Machine Learning Concept Used
- Supervised Learning
- Text Classification
- TF-IDF (Feature Extraction)
- Logistic Regression

---

## 📂 Dataset
A small sample dataset is used:
- `phishing` → suspicious emails
- `safe` → normal emails
